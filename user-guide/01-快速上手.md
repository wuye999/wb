# 快速上手

## 1. 打开项目并准备价格表

请管理员把 SellerOps 项目交给你，在 WorkBuddy 中打开整个项目文件夹。管理员负责准备运行环境和本机连接配置 `data/credentials.json`，包括平台登录、莫斯科仓和物流渠道的关键词。运营负责维护本机 `data/` 里的《商品价格表.xlsx》，WorkBuddy 只读取这份表。

价格表的工作表名保留 `Sheet1`，表头放在第 1 行。改完保存，遇到独占提示就关掉表格窗口。

| 要看的列 | 怎么填 |
| --- | --- |
| 产品中文名 | 填完整名称，例如「旅行杯」。卖家 SKU 留空时，这个名称在表里必须唯一。 |
| 卖家SKU | 商品已有卖家 SKU 时填原值并保持一致。 |
| 尺寸 | 按「长\*宽\*高/毛重」填，例如 `10*20*30/0.5`。尺寸用厘米，毛重用千克。 |
| 最低售价 | 填数值或已计算并保存的公式，用于核价，也可用来给跨店复制的商品定价。 |
| 前缀码 | 在表中带「前缀码」的列填该商品登记的 4 位前缀，例如 `TEST`。保留原表头。 |
| 发货方式 | 三选一，原样填「马帮发货」「WB发货」或「不处理」。 |
| 马帮库存SKU | 只有选「马帮发货」时才填马帮里的库存编码。其余两种方式留空。 |

## 2. 做一次首次体检

> 请做一次本机体检，把运行环境、连接配置文件、商品价格表和各店商品资料的检查结果逐项告诉我，先不要联网。

逐项看结果。运行环境应可用，连接配置文件应已找到，价格表应能打开且没有缺失或重复的必填表头。首次还没同步商品资料时，店铺资料为空可以在连接平台后补齐。体检只确认本机配置文件是否存在，登录是否有效要在需要时单独核对。

## 3. 按需连接平台

需要哪一个平台，就在 WorkBuddy 说「连接 BCS」「连接马帮」或「连接 WB」。首次同步商品通常先连 BCS，使用马帮履约或 WB 后台功能时再接对应平台。

弹出登录窗口时，在平台官网亲自登录并完成滑块、短信等验证。登录成功后按提示正常关窗，等 WorkBuddy 报告连接结果。首次连接 WB 如需选择店铺，按店名和编号逐一核对对应关系。密码留在本机，验证码只在平台窗口填写。

## 4. 同步商品并看图认领

1. 对 WorkBuddy 说「同步全部店铺商品」，等它列出各店同步结果。若有店铺缺失或同步失败，先核对提示，用成功同步的店铺继续。
2. 说「打开待认领工作台」。按回执给出的地址在浏览器打开，看缩略图、出现店铺和完整商品编码，选中价格表里对应的商品。有歧义的先留待核对。
3. 在工作台点「导出审核结果」，然后对 WorkBuddy 说「请导入我刚导出的审核结果，保存已确认的商品归属，并告诉我保存了多少条、还有哪些待确认」。

## 5. 跑通第一次安全预览

> 只预览，把示例店铺(1001)里中文名为「旅行杯」的商品在本店莫斯科仓的每个规格库存设为 25 件。请给我计划单，等我确认。

核对**店铺、商品链接、规格、莫斯科仓和目标值**，再看有没有跳过或被阻止的项目。记下这次的**计划单号**。练习到这里就可以结束。实际要提交时，用本次单号回复「确认提交计划单 P018」，其中 `P018` 是示例单号。只要没说确认提交，就不会改动线上数据。
