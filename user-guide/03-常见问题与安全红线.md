# 03 常见问题与安全红线

## 必须守住的 5 条操作红线

1. **先看计划单，再回复确认**
   所有改价、设折扣、改库存、下架、上架和跨店复制，必须先看 WorkBuddy 给出的计划单（核对店铺、商品、规格、目标值和受阻项），确认无误后再回复「确认提交计划单 XXX」。

2. **只操作你配置的本店默认业务仓**
   每家店铺只认你在 `data/credentials.json` 里配置的本店默认业务仓。如果某家店找不到对应仓库或匹配出多个仓库，系统会立刻停下该店操作，先核对仓库关键词再继续。

3. **报错或超时先看回执，绝不盲目重跑**
   如果提交中途超时或报错，可能已有一部分被平台受理。先让 WorkBuddy 读出本次回执（区分已受理、失败、结果未知），结果未知的不要盲目整批重发。

4. **后台没立刻变，不要反复提交**
   平台对改价、库存和建卡都是异步处理的，提交受理后需要一点时间刷新。看到回执写「已受理」就耐心等待，不要因为后台页面还是旧数字就再提交一遍。

5. **私有文件只留本机，严禁外发**
   `data/` 目录下的凭证文件、《商品价格表》、数据库和登录资料只保存在你自己电脑上，切勿发到公开群、贴进聊天截图或上传到 GitHub。

## 常见报错怎么处理

| 看到什么情况 | 怎么解决 |
| --- | --- |
| **提示登录失效，或弹出平台验证窗口** | 先停下受影响店铺的操作；如果刚提交过写操作，先保留回执。然后对 WorkBuddy 说「连接 WB / 连接 BCS / 连接马帮」，在弹出的官网窗口完成扫码或短信验证后关窗即可。 |
| **提示 Excel 被占用、无法读取或导出** | 把电脑上打开的《商品价格表》或目标 Excel 窗口先保存并关闭，再让 WorkBuddy 重试一遍。 |
| **提示价格表缺列，或最低售价没读到** | 检查 `Sheet1` 第 1 行有没有删掉或改坏「产品中文名」「最低售价」等表头；如果最低售价是公式，先在 Excel 里打开确认已算出数值并保存。 |
| **筛不到商品，或有商品被跳过** | 让 WorkBuddy 列出完整跳过原因：常见是中文名没写全（想模糊找要说「名称包含」）、商品还没在待认领工作台归属、或者太久没同步最新商品资料。 |
| **发货提示缺 SKU，或发货方式为空** | 打开《商品价格表》找到对应商品，把「发货方式」补填为 `马帮发货`、`WB发货` 或 `不处理`；选 `马帮发货` 时必须填好「马帮库存SKU」，保存关表后重新预览。 |
| **提交成功了，但平台后台还是旧价格/旧库存** | 正常现象（平台异步处理 + 本地资料不会自动刷新）。以本次回执里的「已受理」和任务号为准，不用重复提交；想看最新数据时单独说「同步商品」。 |
| **找不到导出的表格或发货 PDF** | 直接问 WorkBuddy「把刚才导出的文件路径发给我」。普通报表在 `exports/`，WB 发货 PDF 在 `exports/fbs_shipments/供货日期/`；如果配送已受理只缺 PDF，让它按原供货单补导即可。 |
| **遇到解决不了的报错，要找维护者帮忙** | 把这 4 样脱敏信息发过去：① 出错时间；② 你当时发给 WorkBuddy 的原话；③ 计划单号或报错截图（遮掉真实店名、商品和订单号）；④ 有没有点击/回复过确认提交。 |
