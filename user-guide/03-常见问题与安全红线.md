# 03 常见问题与安全红线

花 2 分钟看完下面「6 个常见坑」和「5 条红线」，基本可以避开日常运营 95% 的麻烦。

---

## 运营最容易踩的 6 个坑（先看一眼少走弯路）

1. **WB 折扣数字越大越便宜，千万别说反！**
   - 改「售价」改的是**原价（吊牌价）**，不是折后到手价；
   - WB 的「折扣」是打掉的百分比，所以 **折扣 50% 比折扣 30% 更便宜**！想降价要把折扣调大，想涨价要把折扣调小，下单前在预览单里再核对一眼。
2. **货不对板画廊不会自动看图**
   - 系统只会自动帮你标红「前缀冲突」和「售价不是最低价正整数倍」的商品；**商品主图是不是挂错款了，必须你自己肉眼看图核对**，别以为没标红就一定没挂错图。
3. **外发标准商品表，可以删行，但别随便删列**
   - 导出来准备发给其他账号铺货的标准商品表里，自带「源数字码」等交换列，系统要靠它们自动防重复上架。删掉不想要的商品行没问题，**但千万别删列，也别改第 1 行表头**。
4. **一个计划单号就是「整单提交」**
   - 回复确认一个计划单号，整张单子里的商品都会一起提交。如果大批量预览里你只想改其中一家店或几款品，**千万别直接确认这张大单**，直接告诉 WorkBuddy「只保留 A店 和这 3 款商品，重新给我出新预览单」。
5. **让 WorkBuddy 帮忙改《商品价格表》前，记得先关掉 Excel**
   - 平时没你授权，WorkBuddy 绝不会乱动你的价格表；当你明确让它帮忙改表时，**先把电脑上开着的《商品价格表》保存并关掉**，它才能安全备份并修改，也不会损坏里面的公式和嵌入图片。
6. **看到「商品资料有点旧」或「工具有新版本」提示别慌**
   - 本地商品快照超过 24 小时没同步，或者工具代码有新版时，WorkBuddy 会顺口温和提醒你。它**不会偷偷联网同步，也不会自动更新**，你想更新时再让它操作就行。

## 必须守住的 5 条操作红线

1. **先看预览单，核对完再确认**
   所有改价、设折扣、改库存、下架、上架和跨店复制，都必须先看 WorkBuddy 给出的预览清单（大批量先打开它给的完整预览表确认），核对店铺、商品、目标值和跳过项无误后，再回复确认提交。
2. **只操作你自己配置的本店默认业务仓**
   每家店铺只认你在配置里设好的本店默认业务仓。如果某家店找不到对应仓库或匹配出好几个重名仓库，系统会立刻停下该店操作，先核对仓库关键词再继续。
3. **报错或超时先看回执，绝不盲目重跑**
   提交中途万一断网、报错或超时，平台可能已经受理了一部分。先让 WorkBuddy 读出本次回执（看清哪些已受理、哪些失败、哪些结果未知），**结果未知的不要盲目整批重发**。
4. **后台数字没立刻变，不要反复提交**
   平台改价、改库存和新建商品都需要一点异步生效时间。只要回执显示「已受理」，耐心等一会儿就行，不要因为后台页面一时还是旧数字就再提交一遍。
5. **账号密码、配置和价格表只留本机，严禁外发**
   `data` 文件夹里的凭证配置、《商品价格表》、数据库和登录资料全都是你的私有业务数据，不要发到公开群、不要截图暴露真实信息，更不要传到网上。

## 常见报错怎么处理（对号入座）

| 看到什么情况 | 怎么解决 |
| --- | --- |
| **第 0 步装环境时下载很慢或超时** | 直接告诉 WorkBuddy：「下载超时了，请帮我切换国内阿里镜像源并加大超时时间重试」，它会自动换源装好。 |
| **提示要装专用浏览器，或者下载浏览器失败** | 先看你连的是哪个平台：如果只连 BCS 或马帮且已填账号密码，其实**不需要装浏览器**，直接连就行；如果要连 WB 或触发网页验证，让 WorkBuddy 切换国内镜像源重新安装专用浏览器即可。 |
| **提示登录失效，或弹出平台验证窗口** | 先停下受影响店铺的操作（刚提交过写操作的话先留好回执）。然后直接对 WorkBuddy 说「连接 WB / 连接 BCS / 连接马帮」，在弹出的官网窗口里完成扫码或短信验证后关窗即可。 |
| **提示 Excel 被占用、打不开或改不了** | 把电脑上开着的《商品价格表》或其他目标 Excel 窗口先保存并关闭，再让 WorkBuddy 重试一遍。 |
| **体检提示价格表缺列，或某几行填错了** | 体检结果会直接列出出错的 **Excel 行号**和原因。打开《商品价格表》检查 `Sheet1` 第 1 行表头有没有缺「产品中文名」「最低售价」，并按行号把漏填或填错的单元格补好；如果最低售价是公式，在 Excel 里打开确认已算出数值后保存关表。 |
| **筛不到商品，或有商品被跳过** | 让 WorkBuddy 把完整的跳过清单和原因列出来：常见是中文名没写全（想模糊找要说「名称包含」）、商品还没在待认领工作台归属、或者太久没同步最新商品资料。 |
| **处理新增订单时提示缺 SKU，或发货方式为空** | 打开《商品价格表》找到对应商品，把「发货方式」补填为 `马帮发货`、`WB发货` 或 `不处理`；选「马帮发货」时必须填好「马帮库存SKU」，保存关表后重新预览处理新增订单。 |
| **马帮提示库存仓匹配不到、命中多个或与旧编号冲突** | 看报错里列出的本账号启用仓库名称，把配置里的马帮库存仓关键词写具体一点，让它只命中唯一一个仓库（如果同时保留了旧仓库编号，两边必须对得上同一个仓）；程序绝不会瞎猜第一条。 |
| **WB 供货后作废马帮时，有订单被拦下或显示结果未知** | 被拦下（`BLOCKED`）通常是这单在 WB 已被取消、价格表改了发货方式、马帮提前建了预报/交运、或者已开过发票，按明细表原因人工核对即可；结果未知（`UNKNOWN`）先去马帮后台看一眼实际状态，**不要重发**。 |
| **提交成功了，但后台还是旧价格/旧库存** | 正常现象（平台生效需要一点时间，而且本地资料不会自己刷新）。以本次回执里的「已受理」为准，**不要重复提交**，也不要用「直接读缓存」去核对刚改完的价格；过一会儿想看最新数据时，单独说「同步商品」即可。 |
| **找不到导出的表格或发货 PDF** | 直接问 WorkBuddy：「把刚才导出的文件路径发给我」。普通报表都在 `exports` 文件夹，WB 发货打印 PDF 在 `exports/fbs_shipments/日期/`；如果配送已受理只是漏了 PDF，让它按原供货单补导即可。 |
| **遇到解决不了的报错，要找维护者帮忙** | 把这 4 样脱敏信息发过去：① 出错时间；② 你当时发给 WorkBuddy 的原话；③ 计划单号或报错截图（遮掉真实店名、商品和订单号）；④ 有没有回复过确认提交。**注意：密码只说「已填」或「未填」，千万别发密码原文，也别报密码有几位！** |
