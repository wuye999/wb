# SellerOps 多店铺智能运营助手

**用中文说话，就能同时管好几十家店铺的商品资产、选品铺货、新增订单与经营报表。**

SellerOps 是一款专门给电商运营团队用的 AI 协作助手。你**完全不需要懂编程、不需要背任何命令**，只要在 **WorkBuddy** 里用平时聊天的大白话交代任务，它就能自动帮你处理多平台、多店铺的繁琐工作；而且所有会改动线上店铺的操作，都会**先出一份预览清单，等你核对确认一次后再提交**，既省时间，又稳妥防错。

本工具适用于任意支持本地操作的 AI 客户端（如 WorkBuddy、Codex、Claude Code、Cursor 等）。本手册默认以 **WorkBuddy** 为例——它**免费且完全够日常电商运营使用**，零基础也能快速上手。

## 一分钟看懂它能帮你做什么

### 1. 随时摸清所有店铺家底，不再两眼一抹黑
不用一家一家切后台数链接，随时一句话查清全局：
- **每家店多少品**：一次看清所有店铺各有几条在架商品、几条在回收站、商品资料最后更新到什么时候。
- **每款品的分布全景**：按商品中文名一键汇总它在每家店的链接数、售价区间、折扣分布和库存情况，哪家店快断货、哪家标价异常一眼看出来。
- **随时导明细表**：一键导出全店总表或指定单店明细表，拿到 Excel 里直接筛选核对。

### 2. 一句话查出单、发货进度、差评与新增好评
想看哪几天、哪几家店、哪款品，直接用中文问，几秒钟给你汇总表和明细文件：
- **随时查出单与履约状态**：按任意天数或起止日期，查全店或某款商品的出单量、分布店铺、商品编码，以及每单当前进度（待处理 / 分拣中 / 待取件 / 已签收 / 拒收取消等）和退货情况；也能随时查配送中清单。
  - 「查一下近 5 天出单的『旅行杯』在哪些店出单、单量多少、订单状态怎么样」
- **随时追差评、查新增好评**：按任意天数，查 1 星 / 2 星差评、低分预警链接、近几天新增的 4–5 星好评，甚至顺带把「还没有评价的在架商品」一起列出来，口碑变化第一时间掌握。
  - 「查一下 A店 和 B店 近 14 天『旅行杯』的 1 星和 2 星差评情况」
  - 「查一下 A店 和 B店 近 7 天新增了哪些 4 星、5 星好评」

### 3. 多店批量改价、调折扣、改库存，说清楚就一次确认提交
再也不用去十几家后台挨个搜商品、一条条手改。把「哪几家店、哪款品、改成多少」说清楚，WorkBuddy 直接给你出预览单，确认一次就批量执行：
- 「把 A店、B店和 C店里『旅行杯』的原价统一改成 55，再设 35% 折扣」
- 「把全店当前折扣高于 55% 或低于 40% 的商品，统一调成 50%」
- 「把全店名称包含『保温杯』的商品库存统一设为 30 件」

### 4. 自定义周期经营体检 + 爆品一键跨店铺货
一键汇总本账号全部店铺（也可以临时加上其他账号一起算）的经营数据：
- **各店铺出单对比**与全盘总单量
- **每款商品中文名**和**每个商品编码**的近 7 / 14 天有效出单、完单口径退货率、差评情况以及各店链接缺口
- **直接联动铺货**：把报告里挑出来的「卖得好、退货低、口碑好」的优质商品，一键铺到本账号缺链接的店，或批量铺给其他账号的全部店铺。

### 5. 同账号跨店补链 & 跨账号去重铺货 + 全店同步换图改标题
- **同账号补齐漏上链接**：把 A 店某类商品一键复制到其他店铺，自动跳过已有的重复商品，并按《商品价格表》最低售价的倍数自动算好定价。
- **多账号汇总去重铺货**：把其他账号导出的标准商品表一键去重上架到本账号全部店铺，省去反复建卡传图。
- **一店改好，全店同步**：主图、标题、描述、属性或包装尺寸在一家店改好，一句话同步覆盖到其他店的同编码链接。

### 6. 看图批量认领 & 货不对板大图排雷
- **带引导的看图认领工作台**：把各店还没归属的商品按同图、同码自动分组，排好推荐顺序，在浏览器里看图点选、看进度条，点一下导出再把页面给的话术发回 WorkBuddy 就全部归属完成。
- **货不对板大图画廊**：按商品中文名把各店商品大图并排摆出来，系统自动标红**前缀不对**和**价格倍数不对**的商品，你肉眼扫一遍图把挂错的勾出来，就能直接生成对应店铺的下架计划。

### 7. 「处理新增订单」自动分流 + 一键出打印级发货 PDF
只要在《商品价格表》里给每个商品标好发货方式（`马帮发货` / `WB发货` / `不处理`），新订单来了一句话自动分流：
- **处理新增订单（马帮发货）**：自动拉取待处理新单、匹配马帮库存、上传预报并完成交运（如果连了飞书表格，还会自动增量登记，没配飞书完全不影响正常发货）。
- **WB 发货群打单**：同店同品自动合并建供货、提交配送，直接导出排版好的**供货二维码 PDF（58×40mm）**和**订单标签 PDF（40×30mm）**，打开就能打印贴单。
- **WB 供货后自动作废马帮副本**：WB 提交配送后，不用再去马帮网页一条条手工勾选作废；先预览待作废清单，核对通过后再确认逐单作废（只清理马帮待处理副本，绝不影响 WB 买家订单）。

### 8. 省心的小助手细节
- **需要时帮你改《商品价格表》**：平时它绝不乱动你的价格表；当你明确交代要改哪款品的价格、SKU 或发货方式时，只要先关掉 Excel，它会自动备份原表并安全修改，保护好公式和嵌入图片。
- **数据太旧或有新版会自动温和提醒**：本地商品资料超过一天没更新、或者工具有新版本时，WorkBuddy 会顺口提醒你，但绝不会偷偷联网同步或自动升级，全由你决定。

## 为什么可以放心交给它干活？

| 安心保障 | 怎么做到的 |
| --- | --- |
| **先看单，再动真格** | 改价、设折扣、改库存、下架、上架、跨店复制全都先出预览清单，列出店铺、商品、数量和异常项；只要你没回复确认，线上绝不改一分一毫。 |
| **只动你指定的默认仓库** | 每家店只认你自己配置好的本店默认业务仓，找不到或者重名就立刻停下来提醒你，绝不乱动其他仓库。 |
| **账号密码与价格表只留本机** | 你的账号密码、登录状态、《商品价格表》和业务数据全都只存在你自己电脑的 `data` 文件夹里，不会上传到网上。 |
| **不乱重试、全程留记录** | 每次操作都会记下成功、失败和跳过的完整清单；万一中途断网或超时，先看回执再处理，避免重复提交或重复建卡。 |

<summary><strong>技术架构与完整工程能力一览（点击展开，普通运营可跳过）</strong></summary>

SellerOps 采用面向 AI Agent 设计的模块化工程架构，底层由标准化 CLI、本地 SQLite 事务存储、多平台协议适配层与离线自动化测试套件共同保障稳定性：

- **规模与质量保障**：内置 **74 个标准化 CLI 命令**，覆盖商品、上架、目录映射、订单履约、多维报表、会话鉴权与系统维护全链路；配套 **550+ 项全离线自动化测试**（`pytest tests/`）与工程边界/文档一致性自动校验（`scripts/check.py`、`scripts/check_docs.py`）。
- **轻量可靠的技术栈**：基于 Python 3.10+ 构建，核心仅依赖 `requests` 与 `openpyxl`，按需可选 `playwright`（专用浏览器会话续期）与 `reportlab`/`pypdf`（矢量级 58×40mm 供货码与 40×30mm 标签 PDF 排版）；所有快照、映射、冻结计划单与阶段回执持久化至本机 `data/sellerops.db`，天然支持 `--data-dir` 多账号数据目录隔离。
- **冻结计划单与幂等防错**：所有商品写入先经 `ops` 生成冻结计划单（锁定店铺、商品标识、规格 ID、仓库 ID 与目标值），确认后由 `apply --plan` 严格按冻结载荷提交并落盘逐项回执；支持断点续办（如 Open API 上架与发货群 PDF 补取），避免异步接口下的重复提交。
- **典型底层 CLI 调用示例（WorkBuddy 自动编排执行，运营无需手敲）**：

```powershell
# 本机环境与数据契约结构化体检
python run.py doctor --json

# 生成冻结改价计划单 -> 人工确认后按单号原子提交
python run.py ops price --shops 1001 --name "旅行杯" --price 55 --json
python run.py apply --plan P018 --json

# 按天数、店铺、商品中文名筛选差评与星级分布
python run.py report ratings --shops 1001 --days 14 --negative --name "旅行杯" --json

# 生成多店商品综合运营报告（WB 近 7/14 天有效出单、退货、差评、链接缺口）
python run.py report products --shops 1001,1002 --json

# WB 发货群供货预览（提交后自动生成供货码与标签两份 PDF）
python run.py order group-ship --shops 1001 --name "旅行杯"
```
