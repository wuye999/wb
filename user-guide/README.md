# SellerOps 用户手册

SellerOps 是给电商团队用的多店铺运营工具。在 WorkBuddy 里用中文说清要做什么、哪家店、哪些商品或订单，它就能帮你处理商品维护、订单发货、报表和客服。涉及线上改动时，运营先核对预览，再确认提交。

## 核心能帮团队做什么

| 业务 | 省下什么人工活 |
| --- | --- |
| 商品维护 | 在一处预览多家店的改价、折扣、库存和上下架，省去逐店找商品和填写。 |
| 订单发货与 PDF | 按价格表分流订单，办理马帮预报和交运，或为 WB 供货批量导出供货码和订单标签。 |
| 映射与货不对板核查 | 把各店商品归到价格表里的同一款，再并排看图，省去逐条打开链接比对。 |
| 经营报表 | 把订单、评分、退货和出单情况整理成表，省去手工拼表。 |
| 客服与营销 | 集中看买家问题、拟回复、预览促销报名和查看推广建议，少切换几个后台。 |

## 老板最关心的安全与保密边界

1. **先预览再确认。** 改价、调库存、设折扣、下架、上架先出计划单，运营核对无误并回复确认后才提交。
2. **仓库只认本店莫斯科仓。** 涉及仓库时逐店核实，只允许使用该店已确认的莫斯科仓。确认不了就停下。
3. **私有资料留在自己电脑。** 账号密码、价格表和登录会话都保存在本机 `data/`，严禁上传 GitHub。公开仓库只提供程序、说明和空白配置样例。
4. **操作留痕。** 每次提交都有回执和日志，可用来区分已受理、失败和待处理的项目。遇到异常先查回执，提交中或结果未知的项目禁止重发。
