# SellerOps 多店铺智能运营助手

**用中文说话，就能同时管好几十家店铺的商品资产、选品铺货、订单发货与经营报表。**

SellerOps 是一款面向电商运营团队的 AI 协作工具。运营人员无需懂代码、无需记命令，只要在 **WorkBuddy** 里用日常中文下达需求，就能自动完成多平台、多店铺的批量操作；所有涉及线上修改的动作都会**先出预览清单，经人工核对确认后再提交**，既大幅提效，又牢牢守住防错底线。

## 一分钟看懂核心能力

### 1. 全盘商品资产一表掌握，随时看清所有店铺家底
多店铺运营最怕「家底不清」。现在随时可以一键查清全局商品状态，导出全店总表或单店明细，真正做到心中有数：
- **全盘总量**：所有店铺一共有多少在架商品、每家店各有多少条链接、资料更新时间一目了然。
- **品类分布**：每个店铺里，每种商品中文名分别有多少条链接、哪些店铺漏上了哪款品。
- **库存、价格与折扣全景**：某款商品中文名在各店铺的库存分别是多少、售价分布如何、折扣分布是多少，哪家店快断货或标价异常一眼定位。

### 2. 多店灵活筛选，一键批量改价、设折扣、调库存
以前要在十几家店铺后台挨个搜索商品、逐条改价改库存，耗时且极易漏改错改。现在只需一句话，按**指定店铺或全店、商品中文名（精确或模糊包含）、卖家 SKU、商品编码、当前折扣区间**自由组合筛选，一次完成批量调整：
- 「预览把 A 店、B 店和 C 店里『旅行杯』的售价统一改成 55，再设 35% 折扣」
- 「预览把全店当前折扣高于 55% 或低于 40% 的商品，统一调整为 50%」
- 「预览把全店名称包含『保温杯』的商品库存统一设为 30 件」

### 3. 自定义周期全店经营体检 + 精准选品与跨账号铺货联动
支持**自定义任意时间周期**（如近 7 天、14 天、15 天、30 天等），一键汇总本账号全部店铺（还可临时并入其他账号联合统计）的完整经营数据：
- **全店总单量**与各店铺出单对比
- **每个商品中文名**的销量、退货率、差评情况
- **每个 VC 码**的单量、退货率、差评数据，以及各店铺的链接缺口

**最核心的增长闭环**：系统直接从经营报告里筛出**「卖得好、退货率低、差评率低」的优质 VC 码**，一键拿去批量铺到其他账号的所有店铺（或补齐本账号漏上的店铺），把「数据选爆品 → 批量铺货」彻底打通。

### 4. 同账号跨店铺货 & 多账号商品汇总去重铺货
告别手工逐条建卡、传图、算价，把铺货效率提升数倍：
- **同账号跨店补链**：把 A 店某类商品中文名的全部商品，一键复制上架到本账号其他店铺，自动跳过已有链接，并按《商品价格表》最低售价的指定倍数自动定价。
- **多账号汇总去重铺货**：把其他账号所有店铺里某类商品中文名**去重后的全部商品**，或按筛选条件挑出的爆款商品，一键批量上架到本账号所有店铺。

### 5. 一店改好，全店同步商品内容
需要换主图、改标题卖点、补属性或调整包装尺寸时，不用在每家店重复编辑上传。只需在源店改好一次，一句话就能把主图、标题、描述、属性和尺寸同步覆盖到其他店铺的同编码链接，自动匹配各店独立商品码。

### 6. 看图批量认领 & 货不对板大图自动排雷
- **看图认领工作台**：把多家店成百上千条链接自动按同图、同码分组，运营在浏览器里看图点选即可完成归属。
- **货不对板筛查画廊**：按商品中文名并排展示各店大图，自动标红**价格倍数异常**和**前缀冲突**的问题商品，勾完直接生成对应店铺的下架计划，一眼揪出挂错图、标错价的隐患。

### 7. 订单自动分流 + 批量输出打印级发货 PDF
在《商品价格表》里为每个商品标好发货方式（`马帮发货` / `WB发货` / `不处理`），订单自动分流：
- **马帮发货**：自动拉取待处理新单、匹配库存 SKU、上传预报、完成交运（如已接入飞书，还可自动增量登记到飞书表格；未配置飞书不影响正常发货）。
- **WB 发货群**：同店同品自动合并建供货、提交配送，直接导出排版好的**供货二维码 PDF（58×40mm）**和**订单标签 PDF（40×30mm）**，拿到就能直接打印贴单。

## 团队管理与风控保障

| 保障维度 | 具体机制 |
| --- | --- |
| **先预览，后提交** | 改价、设折扣、改库存、下架、上架、跨店复制全部先生成计划单，清晰列出涉及店铺、商品、数量与受阻项；必须经运营核对并回复确认单号后才会提交线上。 |
| **严守默认业务仓** | 每家店铺只操作运营在本地凭证配置（`data/credentials.json`）中指定的本店默认业务仓；逐店唯一核实，匹配不到或存在多个候选仓时立即中止，绝不误动其他仓库。 |
| **数据留本机、零外泄** | 账号密码、登录会话、《商品价格表》和本地数据库全部保存在运营自己的电脑 `data/` 目录中，绝不上传 GitHub；公开仓库只包含程序代码、文档和空白配置样例。 |
| **全程留痕、防重复提交** | 每次操作自动记录计划单号、成功/失败/跳过明细；遇到网络超时或异常先查回执，杜绝盲目重试造成重复建卡或误操作。 |

SellerOps 采用面向 AI Agent 设计的模块化工程架构，底层由标准化 CLI、本地 SQLite 事务存储、多平台协议适配层与离线自动化测试套件共同保障稳定性：

- **规模与质量保障**：内置 **70 个标准化 CLI 命令**，覆盖商品、上架、目录映射、订单履约、多维报表、会话鉴权与系统维护全链路；配套 **454 项全离线自动化测试**（`pytest tests/`）与工程边界/文档一致性自动校验（`scripts/check.py`、`scripts/check_docs.py`）。
- **轻量可靠的技术栈**：基于 Python 3.10+ 构建，核心仅依赖 `requests` 与 `openpyxl`，按需可选 `playwright`（专用浏览器会话续期）与 `reportlab`/`pypdf`（矢量级 58×40mm 供货码与 40×30mm 标签 PDF 排版）；所有快照、映射、冻结计划单与阶段回执持久化至本机 `data/sellerops.db`，天然支持 `--data-dir` 多账号数据目录隔离。
- **冻结计划单与幂等防错**：所有商品写入先经 `ops` 生成冻结计划单（锁定店铺、商品标识、规格 ID、仓库 ID 与目标值），确认后由 `apply --plan` 严格按冻结载荷提交并落盘逐项回执；支持断点续办（如 Open API 上架与发货群 PDF 补取），避免异步接口下的重复提交。
- **典型底层 CLI 调用示例（WorkBuddy 自动编排执行，运营无需手敲）**：

```powershell
# 本机环境与数据契约结构化体检
python run.py doctor --json

# 生成冻结改价计划单 -> 人工确认后按单号原子提交
python run.py ops price --shops 1001 --name "旅行杯" --price 55 --json
python run.py apply --plan P018 --json

# 生成多店商品综合运营报告（出单、退货、差评、链接缺口）
python run.py report products --shops 1001,1002 --json

# WB 发货群供货预览（提交后自动生成供货码与标签两份 PDF）
python run.py order group-ship --shops 1001 --name "旅行杯"
```
