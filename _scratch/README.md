# _scratch — AI 临时工作区

这个目录是给 **AI 写临时脚本、处理文件、生成中间产物/结果文件**用的工作区。

## 用途

- AI 需要写脚本处理文件、跑一次性任务、生成临时结果时，**一律放在这里**。
- 例如：写一个 `xx.py` 读取 `data/商品价格表.xlsx` 做临时统计、生成一份中间 CSV、跑一次数据核对等。

## 规则

- 本目录**已被 `.gitignore` 忽略**，里面的任何文件都不会进入公开仓库，可放心使用、用完自行清理。
- **不要**把临时脚本写进 `wb_ops/`（核心库）、`data/`（数据区）、`docs/`（文档）或仓库根目录。
- 读取项目数据时用相对路径，例如 `../data/商品价格表.xlsx`；也可直接 `import wb_ops`（仓库根目录在 `sys.path` 里时）。
